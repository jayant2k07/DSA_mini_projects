# DSA Mini Projects — C++

This package contains both mini-projects described in the supplied assignment:
1. Campus Route Finder Using Graphs
2. Student Record Search System Using Trees (BST)

Each project folder contains `main.cpp`, `README.md`, and `REPORT.md`.

## Important submission note
Compile and run both projects on your own computer, then capture genuine screenshots of the program outputs. Replace or supplement the report's screenshot checklist with those screenshots. Create a GitHub repository and upload these files; a repository link cannot be created without access to your GitHub account.

## Compiler
- Campus Route Finder: C++11 or later
- Student BST: C++14 or later
